# Four Context failure modes to avoid

https://www.youtube.com/watch?v=BwXremQ-i6I


## 1. Context Poisoning

Solution: Validate. Confirm what is true, and what is false. check it against something real


## 2. Context distraction

Solution: Compact. what is important? if its important, put it in a permanent file. Summarize it. Always validate what you are compacting


## 3. Context confusion

Solution: Curate. do not provide all available tools. Curate the available tools, only expose the tools necessary for the task at hand


## 4. Context clash

Solution: Prune. Delete the old version. do not keep history unlesss there is a real reason for it. if something is worth keeping as history, then perhaps it is worth writing to a permanent file, as per #2 ?
